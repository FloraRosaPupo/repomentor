# Sugestões de projetos

Esta é uma seleção por perfil de contribuição, não um ranking dos repositórios mais usados. As estrelas são consultadas ao vivo somente para o repositório carregado. Popularidade não mede facilidade ou qualidade de onboarding.

| Projeto | Por que aparece | Fonte do próprio projeto |
| --- | --- | --- |
| First Contributions | Tutorial para praticar a primeira contribuição e o fluxo de pull request | [README](https://github.com/firstcontributions/first-contributions) |
| freeCodeCamp | Educação, currículo, plataforma e documentação, com guia para contribuidores | [Getting started](https://contribute.freecodecamp.org/getting-started/) |
| VS Code | Ferramentas de desenvolvimento e issues sinalizadas para primeiros contribuidores; setup pode ser mais complexo | [Contribute](https://github.com/microsoft/vscode/contribute) |

Fontes consultadas em 31/10/2026. Confira as regras de contribuição de cada projeto, inclusive orientações sobre uso de IA. Disponibilidade de issues e labels muda ao longo do tempo.

Repositório público não implica automaticamente licença open source. A interface mostra a licença informada pelo GitHub quando disponível; confirme os termos no projeto original.
