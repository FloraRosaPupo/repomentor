# Código de Conduta

Queremos uma comunidade acolhedora para pessoas com diferentes experiências, identidades e necessidades de acessibilidade.

Trate participantes com respeito, aceite críticas construtivas e prefira linguagem clara. Não são aceitos assédio, discriminação, ameaças, exposição de informações pessoais ou ataques pessoais.

Estas regras se aplicam a issues, pull requests e demais espaços mantidos pelo projeto. Mantenedores poderão editar ou remover conteúdo inadequado e restringir a participação conforme a gravidade e reincidência, explicando a decisão às pessoas envolvidas quando possível.

Para relatar uma ocorrência, procure os mantenedores por um canal privado disponível no perfil do GitHub. Não publique dados sensíveis em issues. Antes de ampliar a comunidade, os mantenedores deverão definir e divulgar um canal privado dedicado para relatos.
